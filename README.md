# Beidou-MS-Fix
针对北斗冒险岛的一些优化和修复/BeidouMS Fix

服务端与客户端均已打包，可在 [Release](https://github.com/deinthoedoka/Beidou-MS-Fix/releases/tag/fix-1.00) 页面下载。
以后均为独立分支，不跟随北斗最新版本进行更新，只针对北斗issues和本issues中提到的bug进行修复

## 2026.10.12更新

**客户端**

- 登录界面标题由BeiDouMS替换成原版MapleStory
- 窗口标题由北斗更换成MapleStory
- 游戏图标高清化，移植冒险岛怀旧服（Maplestory_Classic）
- 40级要求消灭200只黑暗孙悟空的任务（编号30005）不再弹窗，只会显示在任务栏"可以开始"中

**服务端**

- 女神之塔、时空裂缝、元素塔纳托斯、暴君蛋龙、海盗船、拯救 Delli、罗密欧与朱丽叶、鲁塔比迷宫、阿莫利亚、MV 的巢穴、饰品制作专家、阿得拉、工作人员D/E等 NPC 对话汉化
- 40级要求消灭200只黑暗孙悟空的任务（编号30005）不再弹窗

更新补丁使用方法：根据文件夹里的内容分别将补丁复制到服务端/客户端根目录进行替换，原文件记得备份

**已知bug**
1.服务端Web管理后台与游戏账户admin高度耦合，若删除admin账号则无法进入Web后台，而且无法恢复。预计下个版本将对此问题进行修复。

## 2026.10.8更新

**技能与战斗**

- 圣骑士寒冰之剑 / 寒冰钝器现在可以冻结怪物（1 ~ 15 级 1 秒，16 ~ 30 级 2 秒）
- 修正多个冰冻技能的冻结时长翻倍问题
- 修复快速转职一转的时候能力值不返还的问题

**装备系统**

- 永恒 / 重生装备的升级后的技能词条现已生效 —— 恢复GMS083原版的等级（永恒6级，重生4级）

**怪物与地图**

- 修复低掉落倍率下组队任务道具不足
- 超级传送新增闹鬼宅邸外部地图

**后台管理**

- 修复 Web 后台商城部分商品显示异常
- 修复 Web 后台刷新页面掉登录

**客户端汉化**

- 文本汉化率 **87.2% → 98.6%**，写入 12,417 条译文
- **2,842 个任务 100% 中文化**
- 544 条商城礼包名称汉化
